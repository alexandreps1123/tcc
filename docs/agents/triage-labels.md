# Rótulos de triagem

As skills usam estes cinco papéis. No tracker Markdown local, registre o rótulo na linha `Triage:` do ticket.

| Papel da skill | Rótulo local | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação pelo responsável. |
| needs-info | needs-info | Aguarda informações para definir o trabalho. |
| ready-for-agent | ready-for-agent | Escopo suficiente para execução pelo agente. |
| ready-for-human | ready-for-human | Requer execução humana. |
| wontfix | wontfix | Não será implementado. |

Use a coluna de rótulo local quando uma skill solicitar classificação. O ciclo de execução `Status:` de tickets Wayfinder é independente desses rótulos.
