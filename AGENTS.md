## Agent skills

### Issue tracker

Para buscar especificações, registrar tarefas ou publicar resultados das skills, use Markdown local em `docs/tarefas/`. Leia `docs/agents/issue-tracker.md` antes dessas operações.

### Triage labels

Para classificar tarefas, use os cinco rótulos definidos em `docs/agents/triage-labels.md`.

### Domain docs

Antes de explorar o domínio ou documentar termos e decisões, leia `docs/agents/domain.md`: um contexto compartilhado, com `GLOSSARY.md` e `docs/adr/` na raiz do workspace.
